# Orbit Sound

YouTube・YouTube Music の音を、その場で加工して楽しむ Chrome 拡張機能です。
「8Dfy」を参考に、自分用に一から作り直しました（コード・名前・アイコンはすべて独自のものです）。

## できること
- **8D 回転（動き 6 種類）**：音が頭のまわりを動いて聞こえます。ポップアップに、上から見た人と音の粒が動くアニメーションが出ます（実際の音の位置と同期しています）。

  | 動き | 中身 | 方式 |
  |---|---|---|
  | なし | 回転しない（音色だけ使いたいとき） | ― |
  | 左右 | 左右に行き来し、後ろ側でこもる（最初の版の動き） | ステレオ |
  | 円 | 前 → 右 → 後ろ → 左と、頭のまわりを円で回る | HRTF 3D |
  | 8の字 | 顔の前で交差し、右の後ろ・左の後ろへ回り込む | HRTF 3D |
  | らせん | 3周するあいだに上がって下がる（図では粒の大きさ＝高さ） | HRTF 3D |
  | ゆらぎ | 速さを変えたり戻ったりしながら漂う | HRTF 3D |

  HRTF 3D は、頭や耳の形による聞こえ方を再現して、前後・上下まで感じさせる方式です。HRTF だけだと音楽では左右の差が小さい（真横で約10dB）ので、左右の振れを足して強めています（「立体感の強さ」。初期値85%で真横の左右差は約22dB）。

  方向をはっきりさせるため、どの動きにも次の手がかりを足しています（0.4.0〜）。
  - **耳に届く時間の差**：右から来る音は、左耳に少し遅れて届きます（真横で約0.65ミリ秒）。人はこれで方向を強く感じます
  - **距離感**：前では少し大きく、後ろでは少し小さく、こもらせます
  - **部屋の響き**：回っているときだけ、うっすら残響を混ぜます。響きは動かさないので、音だけが頭のまわりを動いて聞こえます
- **左右チェック**：詳しい調整の下にあります。「ピッ音で」は機器が左右を出せるか、「動画の音で」は拡張機能が動画の音を左右に動かせているかを確かめます。
- **Beat Sync（拍）**：曲を聞いてテンポ（BPM＝1分あたりの拍の数）を自動で測り、回転を拍に合わせます（0.5.0〜）。
  | 拍 | 動き |
  |---|---|
  | オフ | 拍に関係なく、回転の速さのとおりに回る |
  | 合わせる | 「8拍で1周」のように、曲のテンポで回る。拍の瞬間に、音が決まった向き（4拍で1周なら 前・右・後ろ・左）に来る |
  | 跳ねる | 拍ごとに「ぽん」とすばやく進み、次の拍まで止まる |

  拍がオンのときは、「回転の速さ」のスライダーが「何拍で1周」（16・8・4・2・1拍）の選択に変わります。右ほど速く回ります。
  - 測り始めてから決まるまで、約5秒（一時停止や早送りのあとは約3秒）かかります。そのあいだ、右側に「測定中」と出ます
  - 速い曲（170 BPM 前後）は、半分のテンポ（85）と測ることがあります。拍の位置は合っているので、回転はゆっくり拍に合います
  - ドラムのない曲や、テンポが大きく揺れる曲では、テンポが決まらないことがあります。そのときは、それまでの速さで回り続けます
- **音色（5 種類）**：そのまま／Slowed（Slowed + Reverb）／Sped Up／重低音／ホール。画面の色も音色ごとに変わります。音色を変えても、動きはそのままです。
- **音量ブースト**：最大 300% まで上げられます。リミッター（音割れを防ぐ仕組み）つきです。
- **Slowed / Sped Up**：再生速度を変えると、レコードのように音の高さも一緒に変わります。
- **詳しい調整**：回転の深さ・立体感の強さ・再生速度・低音・クリアさ・リバーブ量・残響の長さを変えられます。音を変えると、音色は「カスタム」（レモン色）になります。
- **設定の保存**：サイトごとに設定を覚え、次に開いたときも同じ音で始まります。

🎧 8D は、ヘッドホンかイヤホンで聴くと効果がよく分かります。

## 入れ方（はじめの1回だけ）
1. Chrome のアドレスバーに `chrome://extensions` と入力して開く
2. 右上の「デベロッパー モード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」を押す
4. ダウンロードした ZIP を展開し、できたフォルダ（`manifest.json` が入っているフォルダ）を選ぶ
   - ZIP は GitHub の「Releases」からダウンロードできます
   - 展開したフォルダは、消さずに置いてください（消すと拡張機能が動かなくなります）
5. ツールバーのパズルのアイコンから「Orbit Sound」をピン留めしておくと便利です

## 使い方
ポップアップの画面は、上から次の順に並んでいます。Apple のアプリのような、すりガラスの見た目です。

1. **大きな面**：上から見た人と、そのまわりを回る音の粒。**人（頭）をタップするとオン／オフ**です。面の色は音色ごとに変わります。
2. **動きのアイコン**：6 つのアイコンから選びます（マウスを乗せると名前と説明が出ます）。選ぶと、白いつまみが滑って移動します。
3. **音色**：灰色の帯の中から選びます（Apple の切り替えボタンと同じ形）。
4. **音量・回転の速さ・拍**：スライダーで調整します。回転の速さは、右へ動かすほど速くなります。「拍」で「合わせる」「跳ねる」を選ぶと、曲のテンポに合わせて回り、右側にテンポ（♩128 など）が出ます。
5. **詳しい調整 ›**：押すと、下から板がせり上がります。外側を押すか Escape キーで閉じます。「すべて初期値に戻す」もここにあります。

右上の小さな札が、いまの状態です。

| 表示 | 意味・対処 |
|---|---|
| ● 効いています（緑） | 正常です |
| オフ | 人（頭）をタップすると始まります |
| 再生を待っています | 動画を再生してください |
| ページを一度クリック（橙） | ブラウザの決まりで、ページを一度触るまで音の加工を始められません。ページのどこかをクリックしてください |
| 加工できない音声（橙） | Apple Music・Spotify など、著作権保護（DRM）された音声は仕様上加工できません。再生速度だけ変わります |
| このページでは使えません | 対応していないサイトです。拡張機能を入れる前から開いていたタブなら、再読み込みしてください |

## 立体音響の違いが分かりにくいとき
まず「詳しい調整 › 左右チェック」で、どこで止まっているかを確かめます。

| ピッ音で | 動画の音で | 原因と対処 |
|---|---|---|
| 左→右に聞こえる | 左→右に聞こえる | 正常です。動きの「左右」を選び、回転の深さが100%か確かめてください |
| 左→右に聞こえる | 両耳から同じに聞こえる | 拡張機能の問題です。拡張機能の 🔄 とタブの再読み込みをしてください。直らなければ開発側で調べます |
| 両耳から同じに聞こえる | ― | 機器か Mac の設定の問題です（下の 1〜2）。拡張機能では直せません |

1. **イヤホンかヘッドホンで聴く**：パソコン本体のスピーカーでは、左右の音が両耳に混ざるので 8D はほとんど分かりません
2. **端末の設定を確かめる**：Mac の「アクセシビリティ → オーディオ → モノラルオーディオ」がオンだと左右が消えます。「サウンド → 出力」のバランスが片側に寄っていないかも確かめてください。USB ヘッドセットは「Audio MIDI 設定 → スピーカーを構成」で左右が正しく割り当てられているかを見てください。AirPods の「空間オーディオ（ステレオを空間化）」もオフにして試してください
3. **まず「左右」で確かめる**：いちばんはっきり動く動きです。これで動かなければ、拡張機能の再読み込み（🔄）と YouTube のタブの再読み込みをしてください
4. **3D の動きは「詳しい調整 → 立体感の強さ」を上げる**：100% にすると、真横に来たときに片耳だけから聞こえます
5. **右上の札が「ページを一度クリック」のとき**：YouTube の画面のどこか（動画の上など）を一度クリックすると始まります。ブラウザの決まりで、ページを操作するまで音の加工を始められません

## 拡張機能の「エラー」欄について
`chrome://extensions` の Orbit Sound に「エラー」ボタンが出ることがあります。0.3.1 までは、YouTube を開いた直後に「The AudioContext was not allowed to start」という警告がたまっていました（動作には影響しません）。0.3.2 で出ないようにしたので、古い警告は「すべて削除」で消してかまいません。

## タブを離れたとき
- 回転は、音の処理の中の時計（OscillatorNode）で動いているので、別のタブを見ていても止まったりずれたりしません
- Beat Sync は、ページ側のタイマーで 10 ミリ秒ごとに音を聞いています。Chrome は、音が鳴っているタブのタイマーを遅くしないので、裏にあっても測り続けます。もし測れなくなっても、回転はそれまでの速さで続きます
- ポップアップのアニメーションは、ポップアップを開いているあいだだけ動きます（音には関係しません）

## 対応サイト
- **確実に動く**：YouTube（www.youtube.com）、YouTube Music（music.youtube.com）
- **動作は未保証**：Apple Music、Spotify Web。音声が著作権保護つきのため、多くの場合「加工できない音声」と表示されます（音が消えることはありません）

## 元に戻す方法
- **効果だけ止める**：人（頭）をタップしてオフにします。音は加工されずにそのまま流れ、再生速度も元に戻ります
- **Beat Sync をやめる**：「拍」で「オフ」を選びます。回転の速さは、スライダーの秒数に戻ります
- **最初の版の回転に戻す**：動きで「左右」を選びます。0.1.0 と同じ動きです
- **前の画面（0.2.0）に戻す**：`backup/v0.2.0/` の `popup.html`・`popup.css`・`popup.js` を、このフォルダの同じ名前のファイルに上書きし、拡張機能を再読み込みします（音の処理は 0.2.0 と同じなので、画面だけ戻ります）
- **拡張機能を外す**：`chrome://extensions` で Orbit Sound の「削除」を押します。保存した設定も一緒に消えます
- **一時的に止める**：同じ画面で、Orbit Sound のスイッチをオフにします

## 直したあとの反映
コードを書き換えたら、`chrome://extensions` で Orbit Sound の 🔄（再読み込み）を押してください。
そのあと、開いている YouTube のタブも再読み込みが必要です。

## 仕組み（音の流れ）
```
動画の音 → 低音 → クリアさ ─┬→ 左右（StereoPanner＋こもり）→ 耳の時間差 → 距離感 ──┐
                              ├→ HRTF 3D（PannerNode）＋こもり → 耳の時間差 → 距離感 ─┼→ 原音
                              ├→ 中央（深さが100%未満の分）─────────────────────────┘
                              └→ リバーブ（動かす前の音から作る）──────────────────────→ 響き
   原音＋響き → 左右チェック用（ふだんは何もしない）→ 音量（〜300%）→ リミッター → スピーカー
```
- Beat Sync（`engine.js` の `BeatDetector` と `scheduleBeats`）：届いた波形をつなぎ合わせ、ちょうど 10 ミリ秒ごとに周波数の大きさの「増え方」を記録します。8秒ぶんの記録を1拍ずつずらして重ね、いちばん似るずれからテンポを、そろう位置から拍の時刻を求めます。回転は、拍の瞬間に決まった向きへ来るよう、1拍ごとに速さを少しずつ直して予約します（跳ねるときは、拍の中で速さを 2→4→2→0 倍と変えます）
- 耳の時間差は、左右の耳それぞれを DelayNode で 0.8ミリ秒前後遅らせ、その量を位置に合わせて揺らしています。中央の道も同じだけ遅らせて、混ぜたときに音がにじまないようにしています
- 「左右」は「左右の位置」を sin、「前後のこもり具合」を cos で動かしています
- HRTF の4種類は、`engine.js` の `MOTIONS` にある「位置を返す式」（`pos`）が元です。式を周波数成分（フーリエ級数）に分け、揺れの部品（OscillatorNode）で位置を動かすので、タブが裏に回ってもずれません
- ポップアップは、拡張機能から1秒ごとに「位相（いま1周期のどこか）と速さ」を受け取り、同じ `pos` の式でアニメーションを描きます。そのため音と絵が合います
- 動きの種類を増やすときは、`MOTIONS` に `pos` を1つ足すと、音とアニメーションの両方に反映されます（ポップアップのアイコンは `popup.js` の `ICONS` に1つ足します）
- 一度つないだ動画は、ブラウザの仕様でつなぎ直しできません。そのため、オフのときは加工をせずに素通しにしています

## 画面の作り（popup）
- 音色の色は `popup.css` の先頭（`body[data-tone=…]` の `--tone-accent` など）にまとまっています。色を変えるときはここだけ直します
- すりガラスは `backdrop-filter: blur() saturate()` と、背景のぼかした光（`body::before` / `::after`）でできています
- 滑って動く白いつまみは `.thumb`。位置と幅は `popup.js` の `moveThumb` が入れます

## テストのしかた
このフォルダでテスト用のサーバーを起動します（ブラウザに古いファイルを覚えさせない版です。ふつうの `python3 -m http.server` だと、書き換えたあとも古い engine.js でテストが動くことがあります）。

```bash
python3 tools/serve.py
```

次のページをブラウザで開きます。

- `http://127.0.0.1:8765/tests/engine-test.html`：音の計算のテスト（49項目。動きの形・左右と前後・立体感の強さ・耳の時間差・左右チェック・テンポの検出・拍に合わせた回転・跳ねる動き・アニメーション用の位相・切り替え時の安全も含む）。すべて ✔ なら正常です
- `http://127.0.0.1:8765/tests/popup-preview.html`：本物のポップアップ画面を、偽物の拡張機能につないで表示します。上のボタンで「保護つき」などの状態も試せます
- `http://127.0.0.1:8765/tests/content-test.html`：ページ側の処理を手で試すページ（`chrome` の API を偽物に置き換えています）

※ これらのページは、ファイルとして直接開くと（`file://`）動きません。必ずサーバー経由で開いてください。
